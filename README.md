# Welcome to my personal hobby GitHub!

It contains projects I buil(d/t) in my spare time.

## Projects

- **[McChess](https://github.com/MecGlandorff/McChess)** — A small neural chess engine trained from scratch on human games, without engine supervision. Its neural network guides a limited MCTS search instead of Stockfish’s alpha-beta approach. Trained on a local **RTX 4060** GPU, with a **rough local Stockfish-UCI handicap estimate (not FIDE rating!!) of 2653 ELO** across 200 games.

- **[Spine fracture detection](https://github.com/MecGlandorff/C_Spine_fracture_detection_S2)** — 2.5D cervical spine fracture detection using EfficientNetV2 and a bidirectional LSTM. A project from my pre-AI coding days, built with blood, sweat and a lot of tears. It helped me land my first real engineering job, where I met great people, discovered coding agents, and started learning much more, much faster.

- **[News](https://github.com/MecGlandorff/News)** — a local-first AI news intelligence system that turns noisy feeds into source-grounded, evolving story memory. Currently being rebuilt, so main is empty right now. 

- **[Kanon](https://github.com/MecGlandorff/Kanon)** - a skill that gives you, as an engineer, full overview of the systems you are working on. Like a live architecture map.
